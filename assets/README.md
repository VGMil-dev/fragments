# Recursos visuales originales de Fragments

- `hero-fragments.png`: ilustración generada para este proyecto, referencia visual editable mediante futuras iteraciones; no usar como captura de UI.
- `icon.svg`: identidad base en SVG. Debe copiarse también como `apps/web/public/icon.svg` y favicon según soporte del navegador. Sustituye íconos genéricos de Vite / antiguos.
- `flower.svg` / `sparkle.svg`: decoraciones SVG originales y pequeñas; ocultarlas si interfieren con foco o lectura.
- `reference-user.jpg` NO se redistribuye aquí. El brief se derivó de la imagen suministrada en conversación. No copiar composiciones, marcas o textos originales.
- Después de integrar, generar `og-image` optimizado, favicon PNG y apple-touch-icon derivados de la marca nueva si los necesitas. No instalar fuentes propietarias.

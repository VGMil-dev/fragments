# CU-19 — Validar propiedad GitHub en una Review vinculada

Reforzar con una prueba de ruta que, al vincular Review a una propuesta propia, el `owner` enviado debe coincidir con la cuenta GitHub autenticada. Un propietario distinto debe rechazarse antes de consultar el vínculo académico o encolar un trabajo.

Este alcance solo verifica el flujo manual de Review existente; no crea repositorios, no cambia OAuth ni habilita permisos GitHub nuevos. F19 permanece Idea.

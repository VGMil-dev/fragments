# Especificación CU-20 — Acción de continuidad

- Cuando existe una propuesta propia vinculada exactamente a la versión de misión publicada, Mis aulas muestra «Continuar misión» y un nombre accesible con el título de esa misión.
- La acción conserva la propuesta vinculada más recientemente y delega el destino a la lógica existente, que consulta el estado guardado y decide Mentor, Review o Trainer.
- Cuando no hay una propuesta exacta vinculada, el CTA de inicio conserva «Iniciar propuesta».
- No usar nombres o IDs de otras misiones como coincidencia; no cambiar el historial o el comportamiento de reanudación.
- Verificar con Vitest focal, typecheck y revisión independiente. Ego Lite autenticado queda pendiente si el Space no está disponible.

# F01 — Intent
Owner: W1

Problema: Fragments aún no tiene una identidad web ni una entrada utilizable.
Objetivo: implementar la landing del MVP y el sistema visual mínimo responsive usando los tokens y assets aprobados.
No objetivos: no implementar rutas de dominio, DTO, API, persistencia ni lógica de evaluación.
Skills: aplicar `frontend-design` con el brief Pixel Garden y la paleta existente; usar `web-design-guidelines` para revisar accesibilidad y motion; aplicar solo reglas de rendimiento críticas de `react-best-practices`. Usar ego(lite) para validar la vista cuando esté disponible.
Límite de archivos: `apps/web/src/styles`, `apps/web/src/components/brand`, `apps/web/public`, `apps/web/index.html`; no editar contratos, `package.json` raíz ni rutas generales.

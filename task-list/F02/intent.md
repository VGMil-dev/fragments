# F02 — Intent
Owner: W2

Problema: el estudiante necesita un recorrido claro para propuesta, análisis y generación de entregas.
Objetivo: implementar las superficies de estudiante y el cliente API tipado contra `@fragments/contracts`, incluidos estados de carga, vacío y error recuperable.
No objetivos: no inventar calificaciones, endpoints o formas de respuesta; no guardar secretos en el cliente; no implementar dominio ni alterar contratos.
Skills: aplicar `react-best-practices` selectivamente a hooks, data fetching y bundles; usar `frontend-design` y `web-design-guidelines` para continuidad visual, formularios, foco y accesibilidad; validar navegación visual con ego(lite).
Límite de archivos: `apps/web/src/features/{gallery,mentor,review,submissions}`, `apps/web/src/hooks`, `apps/web/src/lib/api`; no editar archivos de marca de W1 ni entrypoints/config compartidos.

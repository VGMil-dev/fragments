# F10.6 — Recuperación de acciones de práctica

Alcance: sortear un reto y registrar el estado propio son acciones de Trainer conectadas al servidor. Si el transporte falla, la pantalla debe salir del estado ocupado y ofrecer recuperación comprensible. Se conserva el reto y el historial ya mostrados; no se añade lógica de reintento automático que pueda duplicar una escritura.

No se cambian contratos, rutas, persistencia, retos, puntuaciones, rúbricas ni llamadas IA.

# Especificación F16.16 — Candidatos visuales

## Criterios

1. Entregar una ilustración por superficie: Mentor, Trainer y Dashboard estudiantil, con paleta Pixel Night y lenguaje visual consistente.
2. Usar WebP de 512×512, mantener cada archivo por debajo de 250 KB y preservar transparencia real verificable.
3. No incluir logo, personajes existentes, texto legible, recompensas, puntuación ni estados de avance ficticios.
4. Registrar SHA-256, tamaño y ubicación de cada archivo.
5. Mantener cada recurso como **Candidato** hasta revisión del propietario; no usarlo en UI ni publicar a producción.

## Fuera de alcance

- Cambios de código o pantallas.
- Aprobación de ubicación visual.
- Capturas Ego Lite o declaración de QA visual.
- Cambios de marca, personajes, navegación, API o contratos.

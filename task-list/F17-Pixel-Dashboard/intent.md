# F17 Pixel Night — Dashboard estudiantil

## Problema
El inicio estudiantil muestra sus recursos reales, pero carece de jerarquía que ayude a elegir el siguiente paso.

## Objetivo
Convertir el Dashboard en un centro de misiones académico: mantener identidad GitHub y actividad verdadera, destacar una sola acción principal, y dar acceso claro a aulas, entregas y Galería con identidad Pixel Night.

## No objetivos
- Crear metas, retos, rachas, puntajes, porcentajes ni métricas nuevas.
- Cambiar contratos, rutas, persistencia, permisos o respuestas del backend.
- Sustituir o generar logos, personajes o assets de marca.
- Afirmar aprobación visual del propietario o validar despliegue.

## Responsable
Agente UI de Dashboard; integración y actualización de TASKS a cargo del arquitecto/planner.

## Criterio de diseño
Tokens Pixel Night F16 (#030407, #1558C9, #D4FF24), contenido español, foco visible, estados veraces y comportamiento responsive/reduced-motion. Referencia candidata, pendiente de revisión del propietario.

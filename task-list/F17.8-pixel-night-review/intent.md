# F17.8 — Review Pixel Night

## Intento

Dar a `/student/review` una jerarquía visual Pixel Night más clara para identificar el repositorio y commit, iniciar o recuperar análisis y leer sus hallazgos, preservando estados, acciones y evidencia que ya entrega el servicio.

## Límites

- No cambiar API, contratos, persistencia, permisos ni evaluación académica.
- No inventar puntuaciones, recomendaciones, evidencia ni estados.
- UX-12 no tiene una referencia visual canónica adjunta/verificada; el resultado es candidato hasta revisión del propietario.
- No se ejecuta análisis Review pagado ni se envía código de repositorios de estudiantes.
